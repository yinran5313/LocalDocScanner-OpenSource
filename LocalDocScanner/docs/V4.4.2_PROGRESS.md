# V4.4.2-rc1 修复与工具续跑

2026-10-04，versionCode11，Android8+/ARM64。保留tiny/medium OCR与同包完整Office引擎。

本版按V4.4.1复查修复页面复制、图像版本/OCR失效、文档聚合/检索同步、逐行PDF文字层校正、搜索PDF尺寸/清晰度、连续拖动、缺页导出、草稿损坏可见、恢复事务/取消、系统保存授权及8种EXIF。旧版全文保存在独立备份字段，整段校订稿不会被后台OCR聚合覆盖。

新增工具后台任务和任务中心。输入/顺序/参数固定；逐页/逐组回执与SHA256用于复用，成功步骤不因最后打包失败丢弃。暂停/失败可查看并另存成功步骤产物。OCR/转图/拆分/批量编辑逐单元续跑；合并/压缩/拼接/签名/对比重试整个原子操作。密码仅通过内存交接，进程退出需重填。证件小文本导出原子提交并登记历史。

源码：jobs/ToolTasks.kt、ToolCheckpoints.kt、ToolTaskWorker.kt、ToolTaskProcessor.kt；ui/tools/ToolTaskPanel.kt、ToolScreen.kt、StructuredWorkbench.kt。复用AndroidX WorkManager2.10.5/Apache-2.0中的CoroutineWorker.doWork/setProgress及WorkManager.enqueueUniqueWork/cancelUniqueWork/getWorkInfosByTagFlow；没有新增调度依赖或复制GPL/AGPL源码。

人工复核字段/表格保留，XLSX导出固定人工稿；PDF签名图片/水印/证书在提交时形成私有副本。Office与放映页共用应用锁会话，锁定时覆盖编辑界面并返回主App解锁，保留原编辑器实例。

新增内部文件容量/引用清单和人工选择清理；保护草稿、任务和Office恢复文件。工具输出Hash、文字预览和历史读取离开主线程；参数写入250ms合并并在提交/离开时刷新。删除旧占位OCR/编辑器、无调用接口及旧全局阈值；一次性patch脚本已移到tools/history并禁止重复运行。工具处理器已从UI拆出，CSV编辑复用内存表格而不逐字符重复解析。

本机发布检查与独立源码构建数据见交付记录。JVM回归88项；Android恢复/Room/EXIF测试须在设备执行。没有连接小米，不报告真机性能或完整流程通过。内部文件保险库、任意复杂PDF转完整可编辑Office、高级扫描缺角/去手指等保留为后续范围；Office完整内核Linux源码重构建、正式签名与升级验收仍需继续。
