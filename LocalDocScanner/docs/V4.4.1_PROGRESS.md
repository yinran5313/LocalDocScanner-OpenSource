# V4.4.1：继续补齐记录

2026-10-04。接续V4.4.0-rc1，仍是开发候选；手机验收尚无设备。

## 新接入的能力

- 密码PDF与编辑/合并/拆分/压缩/OCR/票据等输入联动，逐个解锁。用户明确创建内部无密码工作副本；原文件保持加密，修改权限不足则拒绝。密码不持久化。工具输入存filesDir，不随系统清缓存消失。
- 多图编辑整批处理；逐张预览和调整顺序，书缝按每张单独保存，左右顺序、曲面展平、旋转、滤镜与纠偏；逐图失败提示，可同时合并成PDF。自动纠偏使用OpenCV方向共识，不可靠时保留；白底旋转保留四周。
- 相机增加连续扫描/书籍双页，拍完直接加入持久草稿，书籍一次提交左右两页。基本连续书籍流程已接入；相机内尚无曲面展平、页码OCR排序、漏页检查或去手指；草稿完成后仍须逐页检查。
- PDF现有独立批注可选择、修改备注或删除；保留形状、链接和表单。只读/锁定/无法区分的重复对象拒绝操作。已烧入内容流的图片签名不属于可删除的独立批注。
- PDF原文字对象修改：支持页级Tj/TJ横排字符串，保留原字体和后续文字间距；新文字字体缺字、宽度过大、竖排、Type3、不可见/OCR文字层等明确拒绝。嵌套Form、任意段落重排尚不支持；此功能不能作为安全脱敏。
- 页码起始值、前后缀（{total}）、6个位置和水印角度，配置预览及真实写入同步。
- 敏感区域建议：medium OCR识别当前页面，手机号、身份证/银行卡候选及自定义关键词，使用整条识别行边框加边距。用户选择/调整后才加入永久打码清单；未命中不证明没有敏感信息，不承诺自动完整脱敏。
- CSV/TSV网格分页编辑，引用成熟CSVParser/CSVPrinter保留引号、换行、前导零；最多2万单元格/200列，超限明确要求源码模式。Markdown本地阅读预览和源码切换；原文保存、分享沿用当前修改快照。
- PKCS12证书数字签名：读取用户.p12/.pfx及私钥，RSA/EC、SHA256、增量保存、detached CMS；查看证书身份与SHA256指纹。密码只留当前界面内存；不上传证书。无在线时间戳/吊销查询/CA信任验证；有DocMDP认证限制的PDF保守拒绝。密码学验签及篡改检测纳入回归。
- 文档OCR后台任务：WorkManager持久调度，输入哈希/编辑参数/逐页回执，暂停后保留完成页；续跑复用有效完成页并重试失败页。页面同时修改时条件更新拒绝旧结果；tiny/medium共用模型池。任务按系统调度，强行停止应用后需重开；工具OCR尚未改成后台作业。
- 系统强生物识别用于应用入口解锁；开启需应用密码及系统验证，更改密码会关闭指纹开关。没有读取或保存指纹数据，未声称这是文件加密。
- 密码加密备份：整个ZIP内容用BC AES-256-GCM、128位认证标签、随机盐/nonce及PBKDF2-HMAC-SHA256 60万次加密；头部也认证。备份不产生明文ZIP；恢复须完整验密和认证后才读ZIP并导入。密码错误、篡改、截断或大小超限不提交明文文件。内部文档库仍未整体加密，恢复时短暂缓存明文并在结束时删除。
- 图片编码失败不再报成功，JPEG/草稿清单临时文件提交；结构化复核预览定位到当前PDF页；PDF编辑异常清理临时输出，保留原件。
