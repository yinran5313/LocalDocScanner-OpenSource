# 拾页 V5.1.0

2026-10-14；versionCode 20，ARM64，沿用已有包名与签名。

## 本次补齐
- 照片高清增加独立NAFNet去模糊与非局部均值降噪、强度调节。去模糊384px上下文分块续跑，输入长边最多1600px；降噪无需模型、长边最多2200px。保留透明度。
- 区域修补增加反光/边缘手指候选检测、橙框叠层、逐项选择及采用选区；仍可手动补选。亮度/肤色连通区域规则可能误判彩色印刷；用户确认后才修补。不是通用手部分割模型，不恢复遮挡的真实文字。
- Markdown增加约7.1MiB可选PicoDet版面模型：标题/正文/表格/插图/公式等10类，多栏与跨栏阅读顺序，各表格裁区单独恢复，未归属文字保留，插图与公式保留区域图片。合并单元格结构保存在来源JSON，Markdown预览为普通行列。完整ZIP保留相对图片与位置记录。
- 仅内置medium OCR。其它12包按需安装；9包有核对过的国内平台路径，公式、背景修补、去模糊3包使用离线ZIP。同平台主备端点不是独立镜像。

## 使用
照片高清选择高清/去模糊/降噪；去模糊先导入deblur.zip。
区域修补：检测反光/手指 → 核对橙框取消误判 → 采用选区 → 基础或LaMa修补 → 对照预览保存。
结构Markdown：开启图文版面；恢复行列还需表格模型。分享完整ZIP并整体解压。

## 验收边界
按用户要求暂缓真实样本效果、真机相机/GPS/Office完整流程和多手机性能验收。静态检查、单测和Android模拟器合成样本记录单独交付，不能当作真实手机或精度验收。
不加入摘要问答、PDF到可编辑Word、元素可编辑PPT和外部处理服务。

## 构建
沿用公开仓库Office资源恢复流程。执行`python tools/download_ocr_models.py`获取带长度/SHA校验的medium，再执行`python tools/restore_sentencepiece.py`恢复固定上游源码，并执行`python tools/restore_v51_assets.py`恢复固定KaTeX字体及测试分词模型，然后运行Gradle。本地完整源码包已含匹配medium/Office资源和原生源码；Office为固定预编译运行库，匹配上游源另存本机，不宣称本轮重编译完整Office。
