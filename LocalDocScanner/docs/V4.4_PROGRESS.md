# V4.4.0-rc1：文件闭环与结构化工作台

2026-10-04。开发候选，不能称为全部需求完工；手机验收尚未执行。

## 本轮已接入

- 快速编辑与文本分享先生成当前修改快照；历史Office通过Activity结果同步内部副本与保存位置，内容Hash区分保存版本。
- Office回写失败返回失败回执，保存恢复副本；主App导出记录自动拾取恢复件。引擎另存/导出写跨进程回执，主App记录真实文件与保存URI；增加转PDF入口。
- 外部文件工作副本及快速编辑、工具配置、PDF待编辑清单、输出结果持久化。任务在ViewModel继续；进程回收后明确提示重新处理，不自动重复执行。
- PDF预览共用密码阅读/缩放/页跳转/文内搜索/文字页长按复制。加密阅读使用PdfBox会话，不生成可分享的解密文件。未实现页面上任意区域直接选择文字、目录与缩略图浏览。
- 表单按20项分页覆盖全部字段，区分只读、复选、单选/选项、多选及证书签名字段；长文字超限与不支持字符显式失败，不静默截断。填写仍单行300字上限。
- 失败与未生成文件显示准确，无文件禁用分享；条码复制与URL使用原值。
- 批量发票/收据/自定义正则提取、原文复核、失败页记录、可修改的行列建议；真实XLSX含汇总、明细、原文和复核状态。复杂合并单元格需要人工调整，属于几何建议而非神经网络表格结构恢复。
- SQLite全文索引覆盖扫描OCR、现代Office、文字PDF、TXT/CSV/MD；中文子串搜索。手动更新索引，单文件60MB上限；旧Office需另存现代格式，受密码保护/无文字层文件明确报未纳入。
- 扫描库年份/单位/关键词类型规则预览后批量归档，保留标签。尚不自动移动外部Office/PDF到用户文件夹。
- OCR普通工具批量识别，默认medium，同时TXT+坐标化可搜索PDF，逐页失败提示；图片转PDF逐页解码；长图逐页解码并限制1200万像素/30000边长，必要时降低输出分辨率。
- 两份PDF按页码渲染差异并输出对照PDF/报告，差异标红；无语义判等、移页自动对齐。

## 仍需继续，不伪装已完成

1. 真机升级、Office中文与三格式保存重开分享、微信/小米文件管理器、连续拍摄、OCR精度及黑白算法效果；当前ADB无设备。
2. 连续书籍相机工作流、多图编辑批量输出、自动纠偏、缺角/遮挡分类、自动页序与漏页检查、去手指、长图重叠对齐、PDF去污专门流程、证件拍摄模板。
3. 现有批注选择/修改/删除、原PDF文字对象编辑、敏感信息自动区域建议；页码/水印细化参数。
4. 文档/文件夹加密与生物识别、CSV网格和Markdown渲染。
5. 自动语义分类/本地语义模型、任意复杂PDF转完整可编辑Office、密码学证书签名；正则模板与关键词归档不能冒充这些能力。
6. 工具真正持久后台作业与断点续跑，PDF密码输入与所有处理工具联动；目前中断恢复配置，密码阅读只在预览会话。
7. 完整Office内核从源码重建及当前补丁公开副本独立构建。内置native仍为已核对的官方匹配版本。
