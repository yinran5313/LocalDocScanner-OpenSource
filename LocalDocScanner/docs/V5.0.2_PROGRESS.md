# V5.0.2 — Office 文件名与资源管理修复

本版本修复 V5.0.1 最终静态检查的四项问题，版本 5.0.2 / code 16。

- 文件提供者名称可为空、缺失或没有扩展名：使用非空回退名，安全去扩展名，并统一扩展名大小写；未知复制格式从 MIME 再尝试，无法确定则明确提示，避免空指针或错误保存。
- 文件名查询 Cursor、剪贴板图片输入流使用 try-with-resources。
- SAF 写回先打开源文件，随后在关闭作用域内打开目标；初始化、复制和关闭异常均由原有保存失败/恢复副本流程处理。
- 不修改固定 Office 浏览器资源、OCR 模型或原生库，不新增引擎依赖。沿用原包名及签名，可覆盖旧版本。
- 纠正上次公开同步的目录前缀：9 个 Office/UI/文档文件从仓库根目录归入实际构建的 `LocalDocScanner/` 目录，移除误放副本，确保公开构建包含与本机一致的修复。

`OfficeFileNameTest` 覆盖空值、空白、缺少扩展名、点开头、尾部点、多点名称、中文及土耳其语设备 Locale 的扩展名处理。Cursor/Android 文件提供者的实际行为仍需要设备验收。

验证记录见 `V5.0.2_TEST_RESULTS.json`。本轮仅本机验证；V5.0.1 最后 Office HTML 加载及缩放修改继承到本版，仍未安装到手机验证。没有将历史真机结果当作本版通过。
