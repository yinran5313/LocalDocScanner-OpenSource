# V4 当前代码缺口 → 开源实现 → 具体源码 → 复用许可 → 接入

核验日期：2026-10-03。依据当前 `LocalDocScanner/` 源码，不依据早期手机截图推断。代码位置均相对项目根目录；上游位置相对各仓库根目录。完整上游材料保存在本机 `references/opensource-reuse/`。许可证核验到文件或许可证正文；“已接入”不等于已经通过小米真机验收。

## 当前已经存在的功能

- CameraX 拍摄、多页草稿、原图保留、手动四角裁边、参数预览、撤销和返回裁边；已有透视和黑白 Sauvola 局部阈值。
- Room 文档库、标签/文件夹、搜索、回收站、备份恢复；首页已经使用官方 Material 矢量图标、折叠分组与最近文档长按菜单。
- PDF 合并/拆分/提取/加密/文字提取；PDF 工具具有输入与输出预览、另存至用户选择的位置、分享、结果历史。合并/拆分保留原 PDF 内容，压缩已改为图片对象重编码并保留文字/表单/批注；转图片和永久遮盖改为分页释放位图。
- PP-OCRv6 tiny 与 medium 本地离线识别，普通档 tiny，高精度档 medium；已有可搜索 PDF、表单、批注、签名图片。现在补充 OCR 坐标、真实 Ink 批注、中文表单外观和旋转/CropBox 坐标。
- Office导入、工作副本、同APK Collabora完整编辑器；Java/资源从匹配源码编译，完整native与网页运行时来自SHA校验的官方产物。自动进入真实排版预览，回到工作区保存/分享。首次单APK已构建与静态校验通过，手机往返未验收。
